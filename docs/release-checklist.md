## 首次发布文案

> I built StudyLint because AI-generated study notes often look correct without being traceable. StudyLint checks source files, page and timestamp references, quoted evidence, uncited claims, and conflicting definitions locally—without requiring an AI API. The first alpha supports PDF, PPTX, SRT, Markdown, and text files.
