## 中文

StudyLint 0.5.4 聚焦两类学习场景中的 AI 幻觉：AI 整理笔记时产生的事实与引用错配，以及 AI 论文写作中生成的虚假参考文献。

### 主要功能

- 对照本地 PDF、PPTX、DOCX、Markdown、TXT 与字幕资料核查笔记引用；
- 检查来源文件、页码、时间点、直接引语和结论与指定位置的匹配程度；
- 无来源标注本身不会被判为错误；
- ST005 已避免把 Markdown 表格、时间字段和场景标签误判为术语；
- 通过 Crossref 与 OpenAlex 批量核验论文，并提供知网等人工检索入口；
- 所有笔记与课程资料默认仅在本机处理。

Windows 用户可下载下方的 `StudyLint.exe` 直接运行。

## English

StudyLint 0.5.4 focuses on two learning-time AI failure modes: factual or citation mismatches in AI-generated notes, and fabricated references in AI-assisted academic writing.

### Highlights

- Check note citations against local PDF, PPTX, DOCX, Markdown, TXT, and subtitle sources.
- Validate source filenames, pages, timestamps, direct quotations, and claim-to-location support.
- Missing citations alone are not treated as errors.
- ST005 no longer mistakes Markdown tables, time fields, or scenario labels for defined terms.
- Batch-check paper metadata through Crossref and OpenAlex, with direct links for manual CNKI and other searches.
- Notes and course materials are processed locally by default.

Windows users can download and run `StudyLint.exe` below.
