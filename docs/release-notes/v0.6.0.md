## 中文

StudyLint 0.6.0 把“核验AI生成的参考文献”扩展为面向AI总结与AI论文写作的完整核查工具。

### 下载选择

- **推荐：**`StudyLint-0.6.0-windows-x64-setup.exe`，安装后自动创建桌面和开始菜单快捷方式。
- **免安装：**`StudyLint-0.6.0-windows-x64-portable.zip`，解压后运行`StudyLint.exe`。
- `SHA256SUMS.txt`用于校验下载文件是否完整。

### 本版重点

- AI总结核查支持Markdown、TXT、DOCX、PDF和EPUB，只核查明确标注了来源的结论，不会把“没有引用”本身当作错误。
- 论文存在性核验覆盖Crossref、OpenAlex、Semantic Scholar、arXiv、DBLP、Europe PMC和DOAJ；报告隐藏已通过项，只列出需要用户自行核查的论文。
- 论文内容幻觉核查可连接写作稿论述、引用编号、参考文献和PDF/EPUB原文，并在原稿中标出有问题的位置。
- 可选AI深度核验支持DeepSeek、OpenAI、Gemini、通义千问与自定义OpenAI兼容服务，API Key由用户自行提供且不写入项目文件。
- Windows报告打开、进度百分比、图标、安装器和桌面快捷方式已统一。

> 自动核验用于筛查和定位，不代替用户查阅原文、出版社记录或正式数据库。

## English

StudyLint 0.6.0 expands reference checking into a broader evidence checker for AI summaries and AI-assisted academic writing.

### Choose a download

- **Recommended:** `StudyLint-0.6.0-windows-x64-setup.exe`, which creates desktop and Start-menu shortcuts.
- **Portable:** `StudyLint-0.6.0-windows-x64-portable.zip`; extract it and run `StudyLint.exe`.
- Use `SHA256SUMS.txt` to verify download integrity.

### Highlights

- Check source-marked claims in Markdown, TXT, DOCX, PDF, and EPUB summaries without treating missing citations alone as errors.
- Verify paper records across Crossref, OpenAlex, Semantic Scholar, arXiv, DBLP, Europe PMC, and DOAJ. Passed items stay hidden; only papers requiring manual review appear in the report.
- Connect manuscript claims, citation markers, bibliography entries, and local or lawfully available PDF/EPUB full text, with problem locations annotated in the manuscript view.
- Optionally use DeepSeek, OpenAI, Gemini, Qwen, or a custom OpenAI-compatible endpoint with the user's own in-memory API key.
- Improved Windows report opening, progress feedback, icons, installer packaging, and shortcuts.

> Automated checks are for screening and navigation. They do not replace reading the paper, publisher record, or authoritative database entry.
