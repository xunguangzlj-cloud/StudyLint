# StudyLint v0.7.0

## English

- Detects likely whole-document mismatches between an AI summary and the selected course materials without treating every uncited statement as false.
- Adds optional user-configured AI semantic review to AI summary checking. DeepSeek, OpenAI, Gemini, Qwen, and compatible chat-completions endpoints are supported.
- Restores three manual paper-search entrances for unresolved records: CNKI, Google Scholar, and Baidu Scholar.
- Keeps deterministic checks local; API keys remain in process memory, and AI review is optional.

Download the Windows installer for automatic desktop and Start-menu shortcuts, or use the portable ZIP without installation.
